Open Local Assistant 1.2.2: choose where speech models are stored, and share them with other apps.

Free and open source under the GPL-3.0 license. Everything still runs locally through LM Studio; nothing is sent anywhere unless you choose a hosted provider.

## Highlights
- **Pick your models folder:** Settings → Voice → Model folders now has **Change…** and **Use default**. Point it at a folder other apps use, and the same ONNX models no longer have to be downloaded twice.
- **Your downloads come along:** models the app already downloaded are moved to the new folder, including to another drive. If a complete copy is already there, the app uses it and removes its own duplicate.
- **Tidier layout:** downloaded models are now sorted into `stt`, `tts` and `vad` subfolders. Models from earlier versions are moved into place automatically the first time 1.2.2 starts.
- **Safe in a shared folder:** the app never deletes or overwrites a model it did not download. If the new folder already holds a same-named folder from another app, the change stops before anything is moved. If a move fails partway, everything is put back.

## New since 1.2.1
- Choosable, shareable download folder for speech and voice models.
- Models grouped by type (`stt`, `tts`, `vad`) inside the models folder.
- Deleting a model only ever removes models this app downloaded.

- **Open-Local-Assistant-1.2.2-SHA256SUMS.txt**: SHA-256 checksums for the installer and portable archive

## Requirements
Windows 10/11 64-bit, plus one AI provider: LM Studio with its local server running, or an API key from OpenRouter, Google Gemini or Hugging Face.

## Windows SmartScreen
The builds are not code-signed, so Windows may show "Windows protected your PC". Click **More info → Run anyway**. To check a download, compare `Get-FileHash <file>` in PowerShell with the SHA-256 in the checksum file.
